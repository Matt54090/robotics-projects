# Junior Coder Rescue Team

Open-source educational materials for embedded Linux,
firmware, and system software engineering.


## Topics

- Firmware Development
- RTOS
- Embedded Linux
- Yocto
- Build Systems
- Debugging
- CI/CD
- Robotics
- ROS2


## Repository Structure

```
firmware/
```
Bare-metal and MCU programming materials.

```
os/
```
Embedded Linux and system software exercises.

```
scm/
```
Version control and software engineering practices.
